# KtaOD

Лабораторные работы по дисциплине «Компьютерные технологии анализа и обработки данных» (НГТУ).
Вариант 13. Все расчёты выполнены на языке R.

| Папка | Работа | Данные | Основные методы |
|---|---|---|---|
| [LR1](LR1) | Разведочный анализ данных и проверка статистических гипотез | `var_13.csv` — 200 потребителей услуги «Подключение к сети Интернет» | описательные статистики, графический анализ, критерии нормальности, корреляции Пирсона/Спирмена/Кендалла и частные, ANOVA, Краскел–Уоллис, χ², Фишер, ggpairs |
| [LR2](LR2) | Анализ временных рядов. Метод последовательной идентификации (часть 1) | `л.р.2.csv`, столбец «вар.13» — объём производства по месяцам 2010–2025 | декомпозиция, логистический тренд (nls), гармоники Фурье, периодограмма, ACF/PACF, AR, прогноз на январь–март 2026 |
| [LR3](LR3) | Ассоциативный анализ данных | `lab3_4.csv` — покупки 1230 клиентов магазина техники | транзакции, алгоритм Apriori, support / confidence / lift, графы правил (arules, arulesViz) |

## Состав каждой папки

- `labN.R` — скрипт на R;
- `*.csv` — исходные данные (в LR3 также `basket.csv` и `rules_*.csv`, которые создаёт скрипт);
- `plots/` — графики, которые сохраняет скрипт;
- `output.txt` — полный вывод консоли R;
- `Отчёт_ЛРN_Арещенко.docx` — отчёт;
- PDF/DOCX с заданием.

## Запуск

Нужен R 4.x. Пакеты:

```r
install.packages(c("psych", "rcompanion", "nortest", "ppcor", "corrplot", "ggplot2", "GGally",  # ЛР1
                   "tseries", "forecast", "lmtest",                                            # ЛР2
                   "arules", "arulesViz"))                                                     # ЛР3
```

В начале каждого скрипта указаны путь к библиотеке пакетов и рабочая папка:

```r
.libPaths("D:/R/library")
setwd("D:/labs/LR1")
```

Если репозиторий лежит в другом месте, замените эти строки на свои пути (или удалите `.libPaths`, если пакеты установлены стандартно). Скрипт запускается целиком (`Ctrl+Shift+Enter` в RStudio) или командой `Rscript lab1.R` из папки лабораторной.
